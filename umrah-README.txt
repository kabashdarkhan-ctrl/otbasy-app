Ұмра жолбасшысы — статикалық сайт (серверсіз).
Жариялау: бұл қалтаны Netlify Drop (app.netlify.com/drop), Vercel, Cloudflare Pages немесе GitHub Pages-ке жүктеңіз.
Геолокация үшін сілтеме HTTPS болуы керек (жоғарыдағы хостингтер өзі береді).
Топ (SOS) үшін Supabase-те umrah-group-schema.sql бір рет орындалады; кілттер supabase-config.js ішінде.
Видео (1-2 бөлім): umrah-video/prep.mp4 және umrah-video/practice.mp4 қойыңыз, сосын umrah-app.js ішінде VIDEO_OPEN = true.
